**New: ask Claude about a session.**

Open a Claude Code or Codex session in the island and press **Ask about this session**. Ask what it's doing, or whether it touched anything outside the repo.

- **You see it first.** The chat shows exactly what will be sent and where it's going, and nothing leaves until you press Send. × drops it.
- **What's sent:** your prompts, the agent's replies and one line per tool call, up to 40 KB, newest kept. Never tool outputs or file contents. It's marked "Partial log", because Claude can't see outputs or subagent work and can be wrong about them.
- **Secrets are redacted before the preview.** Redaction matches patterns, so it can miss a password written in plain words: check the preview.
- **No tools.** The answer comes from a chat with no tools at all, through your own Claude Code. Nothing in a session's text can make it run a command, read a file, or approve or deny anything.
- **Your session is only read.** It's never resumed or changed, and nothing new is stored.

A Codex session's log leaves Codex (OpenAI) for Anthropic, and the preview says so. Copilot and Cursor sessions don't have Ask for now; Settings says which agents work.

If you're on 0.8.1 or later, Bouncer offers this update itself: "Bouncer 0.13.0 is ready" in the island; click **Update**.
