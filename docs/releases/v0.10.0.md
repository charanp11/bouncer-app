**New: Bouncer works with the Codex CLI too.**

In Settings, **Codex hooks** → **Install…** shows the exact change to Codex's `hooks.json` and writes it with a dated backup, as for Claude Code. The next time you start Codex it asks you to trust the new hooks once: choose **Trust all and continue**. Updates keep the same hooks, so you trust them once.

- Codex's approval requests get the same cards, rules and risk checks as Claude Code's. On Windows Codex runs its commands in PowerShell, so Bouncer checks them as PowerShell; anything it can't read always asks.
- Cards and sessions say **Codex**. When Codex gives a reason for asking, the card shows it as "Codex says …": its own words, never part of Bouncer's checks.
- Allow or deny only: no question or plan cards, and **Guard every mode** stays Claude Code only.
- Fail-safe as always: if Bouncer is closed, slow or confused, Codex asks in its own prompt.

**Needs Codex 0.145 or newer;** older versions ignore these hooks or can't run them, and Codex then asks as usual (hooks are on by default from Codex 0.124.0, and quoted hook commands work on Windows from 0.145.0).

**Tested with real Codex 0.163.0 and a local test model; not yet with a live model.**

If you're on 0.8.1 or later, Bouncer offers this update itself: "Bouncer 0.10.0 is ready" in the island; click **Update**.
