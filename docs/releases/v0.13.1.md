**A maintenance release: nothing new to learn.**

- The updater plugin moves to 2.14.0. It now checks an update's signature a second time, right before installing.
- The Tauri build tools move to 2.12.4, and Vite to 8.3.5.
- A release now stops before it's drafted if `latest.json` doesn't use the key the updater looks up, so an update can't silently never show.

Bouncer 0.13.2 follows with no changes of its own: it proves an update installs through the new plugin.

If you're on 0.8.1 or later, Bouncer offers this update itself: "Bouncer 0.13.1 is ready" in the island; click **Update**.
