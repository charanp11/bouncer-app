**New: drop a file on the island to check it before you open it.**

Drag a script, an installer, an archive or a config file onto Bouncer. He opens up to catch it, and at once, with no AI and nothing sent anywhere, says in plain words what Bouncer's own checks found:

- what the file really is, from its bytes, not its name (a program named `.pdf` is caught);
- name tricks: right-to-left characters, `invoice.pdf.exe`, hidden characters, look-alike letters;
- risky lines in scripts: download-and-run, encoded commands, turning off Defender, starting on its own;
- what's inside a zip, without unpacking it (zip bombs and paths that escape the folder included);
- where a shortcut (`.lnk`) really points, and what it runs;
- Windows' own signature check, where it was downloaded from, and its SHA-256 so you can look it up yourself. An unsigned program or installer from the internet gets an amber caution.

Bouncer only reads the file: it never runs, opens or unpacks it.

**Is this safe to run?** shows exactly what would go to Claude (the file's name, never its folder; a text file's start with secrets blanked; never a program's bytes), and sends it to your own locked, read-only Claude Code only when you press Send. **Ask about it** attaches the file to your next chat message.

**Known limits:** zip is the only archive Bouncer looks inside (7z, RAR, ISO and others: "can't look inside"); files over 256 MB get no fingerprint or signature check. The report is Bouncer's own checks and Claude's answer is advice: both can be wrong; you decide.

If you're on 0.8.1 or later, Bouncer offers this update itself: "Bouncer 0.9.0 is ready" in the island; click **Update**.
