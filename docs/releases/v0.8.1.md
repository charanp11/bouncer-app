**0.8.1 is the first release with these features.** 0.8.0 was never released: its draft froze when Size, Sound or Volume was changed in Settings, and that is fixed here.

## What's new in 0.8.1

- **Answer Claude Code's questions and plans in the island.** When Claude Code asks you to pick an option or approve a plan, the island shows it too: pick and send, or Approve plan / Keep planning. Only your click answers; the terminal asks at the same time, and whichever you answer first wins.
- **Guard every mode** (Settings, off by default): risky requests in Claude Code's auto, accept-edits and bypass modes stop for a card instead of running.
- **Updates.** Bouncer can now update itself. Once a day it reads this project's latest release file on GitHub (GitHub sees your IP address; nothing else about you is sent). When a newer version is out, the island shows "Bouncer X.Y.Z is ready" with an **Update** button; nothing installs until you click it, and it waits while a card or chat is up. The installer's signature is checked first; your hooks, rules, settings and history stay. Turn it off in Settings → **Check for updates**. For an email when a release comes out, use **Watch → Custom → Releases** on the GitHub page.

**Known limits:** with Guard every mode on, a `claude -p` run refuses risky requests instead of asking; typed ("Type something") answers and "approve + accept edits" for a plan stay in the terminal.

**Coming from 0.7.0?** 0.7.0 has no updater: install 0.8.1 by hand once (download the installer below and run it; your hooks, rules, settings and history stay). From 0.8.1 on, updates come to you.
