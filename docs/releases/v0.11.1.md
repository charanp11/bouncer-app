**A small safety fix: Bouncer's Claude Code hooks now say they're Claude Code's.**

Until now Bouncer worked out which agent was calling from the shape of the message. Newly installed Claude Code hooks now carry a label (`--agent claude-code`), so Bouncer always knows they come from Claude Code, whatever Claude Code sends in future versions.

**What you'll see after updating:**

- In Settings, **Claude Code hooks** shows **"Update needed"** with a **Re-install…** button.
- Click **Re-install…**. Bouncer shows the exact change to `~/.claude/settings.json` (the label added to each of Bouncer's entries, nothing else).
- Click **Write changes** to save it (a dated backup of the old file is kept). The row then shows **Installed**.

**Your old hooks keep working meanwhile.** Nothing stops if you re-install later; Bouncer never changes `~/.claude/settings.json` without showing you the change and getting your yes.

Codex CLI and Copilot CLI hooks are unchanged.

If you're on 0.8.1 or later, Bouncer offers this update itself: "Bouncer 0.11.1 is ready" in the island; click **Update**.
