# Credits

Bouncer's character, icon and sounds are drawn or generated in code for this
project.

## Copied code

None yet. Any code copied from another project is listed here with its source,
license and copyright notice, and keeps that notice in the file.

## Studied, not copied

- [Coucou](https://github.com/Louis-CFM/coucou) (MIT): the relay's deadline
  pattern and the named-pipe server SID check informed Bouncer's relay design.
  No code was copied.
- Date conversion in `bouncer` follows Howard Hinnant's public
  `civil_from_days` algorithm, written from its description.

## Dependencies

Third-party crates and npm packages are listed in `Cargo.lock` and
`package-lock.json`; their licenses are checked in CI by `cargo deny`.
